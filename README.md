# Ирина Кичигина — педагог раннего развития

Сайт-визитка педагога: три страницы с погружением в студии Монтессори и Логоритмики.

## Страницы

| Файл | Содержание |
|---|---|
| `index.html` | Визитная карточка: о педагоге, студии, отзывы, контакты |
| `montessori.html` | Студия Монтессори: тезисы, зоны среды, ход занятия, **интерактивная диагностика развития 12–24 месяцев** |
| `logoritmika.html` | Студия Логоритмика: почему ритм будит речь, формула занятия, кому важно |

## Структура

```
├── index.html
├── montessori.html
├── logoritmika.html
└── assets/
    ├── css/style.css        — дизайн-система (палитра, типографика, анимации)
    ├── js/main.js           — кастомный курсор, переходы между страницами, reveal-анимации, параллакс
    ├── js/diagnostic.js     — диагностика: данные, вкладки, радар-график, печать отчёта
    └── img/                 — иллюстрации (сгенерированы ИИ), фото педагога, фавикон
```

## Деплой на GitHub Pages

1. Создайте репозиторий и загрузите все файлы в корень:
   ```bash
   git init
   git add .
   git commit -m "Сайт педагога: визитка, Монтессори, Логоритмика"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<репозиторий>.git
   git push -u origin main
   ```
2. В настройках репозитория: **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

Сайт статический: сборка не нужна, всё работает из корня репозитория.
Все пути относительные — страницы корректно открываются и из подпапки GitHub Pages.

## Примечания

- Диагностика хранит отметки в `localStorage` браузера.
- Кнопка «Распечатать» открывает системный диалог печати отчёта
  (там же можно выбрать «Сохранить как PDF»).
- Шрифты Cormorant Garamond и Jost подключены с Google Fonts.
